Une revue en trois gestes

VibeScreener vit dans la barre de menus. Rien à ouvrir avant de commencer : le raccourci suffit.

  1. 1⇧⌘2

    Figez l'écran

    Le raccourci fige l'écran, quelle que soit l'app ouverte. Il se change dans les réglages.

  2. 2Clic

    Pointez et parlez

    Un clic sur l'élément pose le point et ouvre le micro. Vous parlez, c'est transcrit. Glissez pour entourer une zone, ou tapez votre commentaire si vous préférez.

  3. 3⌘E

    Exportez pour l'IA

    • PDF, à coller dans le chat de Claude ou de ChatGPT
    • Markdown et images, pour Claude Code ou Cursor
    • PowerPoint

Les captures suivantes s'ajoutent à la même session et les points continuent leur numérotation : toute une revue d'écrans part en un seul export.

Un croquis à l'iPad

Ce qui se dessine mieux qu'il ne se dit : tracé à l'Apple Pencil, le croquis rejoint le point en cours.

  • Menu de l'icône > « Appairer une tablette », puis le QR code scanné avec l'appareil photo de l'iPad.
  • Rien à installer : Partager > « Sur l'écran d'accueil ».
  • En Wi-Fi comme en 4G, chiffré de bout en bout.

L'installation branche VibeScreener à Claude Code s'il est présent ; sinon, la commande est dans les réglages, onglet « Claude Code ». VibeScreener doit être lancée.

Vos captures restent sur votre Mac

Captures, sessions et dictée ne quittent pas votre Mac. Pas de compte à créer.

Dictée hors ligne

La transcription tourne sur le Mac (whisper.cpp). Le moteur par API, facultatif, envoie l'audio au service que vous choisissez.

Tablette chiffrée

Le relais ne voit que des messages chiffrés (AES-GCM). La clé est dans le QR code et ne passe jamais par le serveur.

Claude Code en local

Le serveur lu par Claude Code n'écoute que sur votre Mac (127.0.0.1) et refuse les requêtes venant d'un navigateur.

Questions fréquentes

Que se passe-t-il à la fin de l'essai ?

Sans licence, VibeScreener ne fait plus de nouvelles captures. Vous ne perdez rien : vos sessions, vos exports et la lecture par Claude Code restent accessibles.

Sur quels ordinateurs ?

Un Mac Apple Silicon (M1 ou plus récent) sous macOS 13 ou plus. Une licence s'active sur 3 Mac. Windows est prévu, mais pas encore disponible.

Faut-il une connexion Internet ?

Pas pour capturer ni dicter : la transcription se fait sur le Mac, une fois le modèle de dictée téléchargé au premier lancement (547 Mo). Internet sert à la tablette, aux mises à jour et à la vérification de la licence.

Pourquoi macOS bloque-t-il la première ouverture ?

VibeScreener n'est pas signée par Apple. La commande d'installation évite ce blocage ; avec le .dmg, glissez l'app dans Applications, puis Réglages Système > Confidentialité et sécurité > « Ouvrir quand même ». Pour la même raison, macOS redemande les autorisations écran et micro après chaque mise à jour.
